# 万栖源全品类资源撮合小程序

万栖源是面向居民、商家与服务资源方的全品类资源撮合小程序。平台提供需求发布、资源匹配、线索解锁、反馈申诉、客服工单与履约留痕能力；交易资金在线下自行结算，系统不做托管、分账或代收代付。

## 当前实现范围

- 微信小程序首版页面：`首页`、`匹配`、`消息`、`我的`、发布、语音确认、发布详情、匹配详情、解锁、认证范围、额度账户、反馈申诉。
- 双角色工作台：居民与师傅可在端内切换视角。
- 开发环境 mock：需求、匹配、消息、品类、额度流水等本地模拟数据已覆盖家电维修、家政保洁、局部家装、劳务服务、设备租赁、农机服务、同城运输。
- 深色主题：参考“蓝黑底色 + 亮蓝识别光球 + 橙色发布动作”的视觉方向。
- 自定义底部导航：使用页面内 `Image` 渲染 PNG 图标，避免原生 tabBar 图片在模拟器中缓存或路径异常导致破图。
- 合规边界：无 C 端与 B 端在线聊天；双方仅在线索解锁后电话联系。客服、申诉、服务确认单、72 小时反馈与评价承担平台留痕。

## 技术栈

- Taro 4.1.9
- React 18
- TypeScript
- Sass Modules
- Zustand
- Node.js 内置测试框架

## 目录结构

```text
src/
  assets/
    icons/          页面内 PNG 图标
    tabbar/         历史 tabBar 图标资源
  components/
    BottomNav/      自定义底部导航
    BusinessPage/   业务详情页通用框架
  data/             本地 mock 数据与图标映射
  domain/           可复用业务规则
  pages/            小程序页面
  services/         接口调用封装，开发态默认读取本地 mock
  store/            角色、登录态、额度等会话状态
  styles/           主题变量、兼容样式、通用变量
  types/            领域类型
tests/              回归测试
docs/               产品、交互与研发文档
cloudfunctions/     早期云函数样例，后续可按服务端方案替换
```

## 快速开始

安装依赖：

```bash
npm install
```

构建微信小程序：

```bash
npm run build:weapp
```

运行测试：

```bash
node --test tests/*.test.js
```

构建产物输出到 `dist/`，项目配置中的 `miniprogramRoot` 指向该目录。

## 关键规则

- C 端永久免费，平台收入来自师傅线索解锁费或额度包充值。
- 解锁只消耗额度余额，不在解锁环节调用支付。
- iOS 端不展示充值入口、付费引导、外链、二维码或客服收款话术。
- 中置信线索禁止独锁，高危品类需人工核验后入池。
- 解锁后 72 小时必须四选一反馈；不反馈冻结等额额度。
- 仅“无效打不通或未发布”进入退款核验，“价格不合适”不退款。
- 平台不提供供需双方 IM、留言板、站内聊天。

## 测试覆盖

当前测试覆盖：

- 小程序运行时代码不引用 `process.env`
- 开发环境 mock 数据覆盖列表、匹配、消息和全品类示例
- 页面暴露 v4 文档要求的客服、确认单、额度效率、供需双池等能力
- 图标资源存在且被页面使用
- 业务规则：优先窗口解锁权限、发布状态动作
