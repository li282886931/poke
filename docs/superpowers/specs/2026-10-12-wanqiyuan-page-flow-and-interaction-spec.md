# 万栖源全品类资源撮合平台

## 页面流与逐页交互规格

## 1. 产品边界

本规格覆盖首发城市、首发品类下的微信小程序和运营后台。小程序由居民与师傅共用，按认证角色展示不同工作台；运营后台负责审核、配置、争议和审计。

平台售卖可信线索，不处理线下服务的订单金额、支付、托管或分账。用户完成的结果是：居民找到可联系资源，师傅在合规扣减额度后获得联系方式，运营可审计地完成审核、退款和申诉处理。

### 1.1 角色

| 角色 | 可完成的任务 | 不可执行的任务 |
| --- | --- | --- |
| 游客 | 浏览公开的脱敏资源，发起登录 | 查看联系方式、发布、解锁 |
| 居民 | 发布需求或资源、确认识别结果、查看匹配、反馈、申诉 | 查看师傅的敏感资质、直接修改审核状态 |
| 师傅 | 完成入驻、维护服务范围、查看匹配、解锁、反馈、申诉 | 绕过额度或优先权获取联系方式 |
| 审核员 | 审核线索、资质和内容，要求补充 | 直接修改额度、信用和等级 |
| 仲裁员 | 处理退款与申诉，回写处罚或退款结论 | 修改原始事实反馈 |
| 配置管理员 | 管理品类、区域和规则草稿，发起发布 | 绕过审批直接生效配置 |
| 审计管理员 | 查看审计与导出申请 | 直接编辑业务数据 |

### 1.2 全局状态

| 对象 | 状态 | 用户可见含义 |
| --- | --- | --- |
| 发布单 | 草稿、已提交、待确认、待复核、可售、匹配中、独锁中、已关闭、已过期 | 当前可做的操作与下一步 |
| 匹配单 | 待推送、已推送、优先窗口中、可解锁、已解锁、已失效 | 师傅是否可查看或解锁 |
| 解锁单 | 创建中、已解锁、联系人授权异常、已撤销、退款处理中、已退款 | 联系方式可见性和额度结果 |
| 申诉单 | 草稿、已提交、待补充、处理中、已结案、已撤回 | 证据与结论进度 |
| 配置版本 | 草稿、待审批、已生效、已回滚、已归档 | 生效范围和可编辑性 |

## 2. 信息架构与主流程

### 2.1 小程序导航

```text
首页
├─ 发布需求 / 发布资源
│  ├─ 语音识别确认
│  ├─ 动态表单
│  ├─ 预览提交
│  └─ 发布详情 / 审核状态
├─ 匹配
│  ├─ 居民：我的需求匹配
│  └─ 师傅：可响应匹配
├─ 消息
├─ 我的
│  ├─ 认证与入驻
│  ├─ 我的发布 / 我的资源
│  ├─ 额度与解锁记录
│  ├─ 反馈与申诉
│  └─ 设置
└─ 收藏
```

### 2.2 居民主流程

```text
首页 → 语音或手动发布 → 识别确认 → 动态表单 → 提交核验
→ 待确认/待复核 → 匹配中 → 资源响应列表 → 反馈或申诉 → 关闭
```

### 2.3 师傅主流程

```text
认证与服务范围 → 师傅首页 → 匹配列表 → 匹配详情
→ 优先窗口或普通解锁 → 确认额度扣减 → 联系方式授权
→ 服务跟进 → 反馈或申诉
```

### 2.4 运营主流程

```text
工作台 → 审核队列 / 匹配监控 / 退款申诉 / 配置管理 / 审计导出
```

## 3. 小程序逐页规格

### MP-01 启动、登录与角色识别

| 项目 | 规则 |
| --- | --- |
| 入口 | 首次启动、登录失效、访问需登录功能 |
| 内容 | 品牌标识、微信授权登录、用户协议与隐私政策入口 |
| 成功结果 | 创建或恢复会话；返回可用角色、认证状态和平台能力开关 |
| 首次登录 | 进入身份选择：居民、师傅、两者均开通 |
| 失败处理 | 授权取消时停留本页，可浏览脱敏内容；登录异常可重试 |
| 禁止项 | 未登录不得发布、解锁、查看消息详情或提交反馈 |

### MP-02 首页

| 区域 | 字段与交互 |
| --- | --- |
| 顶栏 | 菜单、城市切换、消息未读数、发布按钮 |
| 语音发布 | 长按开始、松开结束；录音中显示取消区域与时长；超过平台允许时长自动停止 |
| 实时撮合 | 仅显示已脱敏的动态文案、品类和区域，点击进入公开资源列表 |
| 品类入口 | 仅显示当前城市已开放品类；点击进入预设品类发布或筛选页 |
| 附近推荐 | 卡片显示品类、行政区、距离区间、可用时间、可信标识；联系方式和精确坐标不展示 |
| 角色切换 | 同时拥有两种认证角色时可切换；切换只改变工作台，不改变已发布数据 |

首页存在语音服务不可用、定位授权拒绝、无推荐资源三种独立状态；每种状态均保留手动发布入口。

### MP-03 语音识别确认

| 项目 | 规则 |
| --- | --- |
| 入口 | 首页语音结束或发布页点击语音输入 |
| 展示 | 识别原文、品类、地点、规格、时间等结构化标签 |
| 编辑 | 标签和原文均可编辑；删除标签后不自动恢复 |
| 操作 | 重新说、转手动填写、确认并继续 |
| 确认规则 | 用户确认前，识别字段不参与匹配或审核 |
| 异常 | 无有效文本、识别超时、字段置信不足时，提示转手动填写，不阻塞发布 |

### MP-04 发布类型与品类

| 字段 | 规则 |
| --- | --- |
| 发布类型 | 需求、资源；创建后不可直接互换，需新建草稿 |
| 城市 | 默认当前城市；仅可选择已开放城市 |
| 行政区 | 必填，受城市约束；定位结果仅为建议 |
| 品类 | 必填，只显示开放品类；切换品类需确认并清除不兼容的动态字段 |
| 发布入口 | 可从首页、侧栏、空状态进入 |

### MP-05 动态表单

| 区域 | 字段与规则 |
| --- | --- |
| 基础信息 | 标题、描述、行政区、位置范围、期望时间、图片；必填项由品类配置决定 |
| 品类规格 | 使用配置定义的选择、数字、日期、文本、枚举字段；`required_match` 字段必须完整有效 |
| 联系方式 | 经授权后采集；公开页不展示，只有合规解锁后允许受控显示 |
| 位置 | 可输入地址或选择地图位置；公开使用行政区和距离区间，精确坐标仅用于匹配 |
| 图片 | 提交前必须完成内容检查；检查中不可提交 |
| 草稿 | 可保存、不触发审核；删除草稿需二次确认 |

字段错误显示在字段下方，提交时聚焦第一个错误字段。网络失败保留本地输入，用户可重新提交。

### MP-06 发布预览与提交

| 操作 | 规则 |
| --- | --- |
| 预览 | 以公开脱敏视图展示，明确哪些字段仅在成功解锁后可见 |
| 提交 | 先确认内容真实、联系方式可用；提交后生成发布单 |
| 结果 | 显示“处理中”而非承诺立即匹配；跳转发布详情 |
| 可编辑性 | 已提交且未进入可售前可撤回修改；进入可售后关键规格修改需产生新版本并重新核验 |

### MP-07 发布详情与审核状态

| 展示 | 规则 |
| --- | --- |
| 状态时间线 | 草稿、已提交、待确认、待复核、可售、匹配中、关闭/过期 |
| 审核原因 | 驳回或待补充时显示可执行原因和需修改字段，不暴露审核员信息 |
| 匹配摘要 | 展示匹配数量、最新响应时间和处理进度 |
| 操作 | 编辑、补充、暂停、重新发布、关闭、申诉；动作由当前状态控制 |
| 关闭 | 需选择关闭原因；关闭后停止新解锁，已解锁记录仍可在历史中查看 |

### MP-08 居民匹配列表

| 项目 | 规则 |
| --- | --- |
| 入口 | 发布详情、底部“匹配”、匹配消息 |
| 筛选 | 发布单、品类、区域、状态；默认当前进行中的发布单 |
| 卡片 | 资源类型、服务区域、距离区间、可用时间、可信标识、响应状态 |
| 操作 | 查看脱敏详情、收藏、标记无效、进入反馈 |
| 空状态 | 分为“审核中尚未匹配”“无符合资源”“发布已关闭”三类，并提供对应下一步 |

### MP-09 师傅入驻与服务范围

| 字段 | 规则 |
| --- | --- |
| 基础身份 | 姓名、手机号、实名认证状态；已认证字段不可直接改写 |
| 资质 | 品类资质、证照图片、有效期；高危品类缺少资质不可启用服务 |
| 服务范围 | 城市、行政区、服务半径、品类、规格能力、可服务时间 |
| 服务状态 | 可接单、暂停、休假；暂停后不可获得新匹配，不影响已解锁记录 |
| 审核 | 提交后进入审核；审核完成前仅可编辑草稿或补充材料 |

### MP-10 师傅首页与匹配列表

| 区域 | 规则 |
| --- | --- |
| 顶部状态 | 认证、服务状态、可用额度、待处理匹配、优先窗口 |
| 匹配卡片 | 品类、区域、距离区间、规格、时效、可信标识、发布时间 |
| 筛选 | 品类、区域、时间、可解锁状态；只能筛选本人服务范围内数据 |
| 排序 | 按匹配规则输出的固定顺序展示；前端不得更改硬过滤结果 |
| 空状态 | 服务范围未配置、审核中、当前无匹配、因处罚不可接单分别提示 |

### MP-11 匹配详情

| 展示 | 规则 |
| --- | --- |
| 脱敏信息 | 需求摘要、品类规格、行政区、距离区间、服务时间、发布时间 |
| 匹配说明 | 仅展示“符合的服务范围/规格/时效”等原因；不展示完整风控与排序因子 |
| 优先窗口 | 显示窗口拥有者可解锁；非拥有者只展示剩余时间与不可操作原因 |
| 普通池 | 窗口结束且线索可售时才可操作解锁 |
| 失效状态 | 线索关闭、已满额、资格失效时不可解锁，并保留返回列表入口 |

### MP-12 解锁确认与结果

| 阶段 | 规则 |
| --- | --- |
| 确认页 | 展示额度消耗、可用余额、退款适用条件、发布单摘要、一次性确认按钮 |
| 提交中 | 按钮禁用，防止重复请求；离开页面后可从解锁记录恢复结果 |
| 成功 | 创建解锁记录，展示受控联系方式、可联系时限、服务跟进入口和流水入口 |
| 失败 | 不扣减额度；明确余额不足、优先权不符、线索已失效、资格不符或系统异常 |
| 联系人异常 | 解锁已生效但授权暂不可用时显示补偿状态，禁止重复解锁 |

### MP-13 消息中心

| 类型 | 跳转规则 |
| --- | --- |
| 审核与补充 | 跳转发布详情的对应状态 |
| 匹配与优先窗口 | 跳转匹配详情 |
| 解锁与退款 | 跳转解锁记录或退款详情 |
| 反馈与申诉 | 跳转待处理反馈或申诉详情 |
| 系统通知 | 跳转通知详情或配置页 |

支持全部、未读、业务类型筛选；读状态只影响个人视图，不影响业务状态。

### MP-14 反馈、退款提示与申诉

| 模块 | 规则 |
| --- | --- |
| 反馈 | 在规定窗口收集“已联系/未联系/服务完成/信息不实”等事实及说明、证据 |
| 退款提示 | 仅根据已存在的规则结果展示“可申请/处理中/不适用”；用户不能自行决定退款金额 |
| 申诉 | 选择关联发布、解锁或处罚；填写事实、诉求、证据；提交后不可修改原始内容，可补充证据 |
| 结案 | 展示结论、理由、额度影响、信用影响和可见范围 |
| 异常 | 证据上传失败可重试；重复提交时定位既有申诉单 |

### MP-15 我的、额度与设置

| 页面 | 内容与规则 |
| --- | --- |
| 我的 | 角色、认证状态、进行中业务、快捷入口 |
| 我的发布/资源 | 按状态筛选，进入发布详情；不展示他人数据 |
| 额度账户 | 可用、冻结、消费、退款流水；余额只读 |
| 解锁记录 | 解锁对象脱敏摘要、状态、额度影响、联系人授权状态 |
| 收藏 | 收藏的脱敏资源；资源失效时保留失效标记 |
| 设置 | 城市偏好、通知、隐私与账号注销入口；注销前检查未结案业务 |

## 4. 运营后台逐页规格

### ADM-01 登录与权限

管理员登录后按角色加载菜单和数据范围。城市范围由服务端授权决定，页面筛选不能扩大可见范围。会话失效返回登录页并保留非敏感筛选条件。

### ADM-02 工作台

| 区块 | 内容 |
| --- | --- |
| 待处理 | 待审核线索、待补充资质、待仲裁申诉、待审批配置 |
| 运行异常 | 任务失败、重复投递、对账差异、联系人授权异常 |
| 快捷操作 | 进入处理队列、查看关联业务、查看审计 |
| 约束 | 不提供直接修改余额、信用、等级、匹配资格的入口 |

### ADM-03 线索与资源审核

| 区域 | 规则 |
| --- | --- |
| 列表 | 城市、品类、状态、置信级别、提交时间、处理时限筛选 |
| 详情 | 原始提交、脱敏公开预览、内容检查结果、置信因子、历史版本、证据 |
| 操作 | 通过、驳回、要求补充、转复核；每次必须填写原因 |
| 结果 | 写入状态和审计记录；通知发布者；驳回不得进入售卖或独锁 |

### ADM-04 匹配监控

展示发布单的候选快照、硬过滤拒绝原因、排序摘要、投递状态、去重结果和规则版本。允许发起符合权限的重算或补偿投递，不提供跳过区域、资质、处罚等硬过滤的操作。

### ADM-05 退款与申诉处理

| 页面 | 规则 |
| --- | --- |
| 退款队列 | 按来源、关联解锁、状态、额度影响、时效筛选 |
| 退款详情 | 展示反馈、证据、关联账务与历史处理；只允许退还额度，不发起线下服务款退款 |
| 申诉队列 | 展示事实、证据、关联对象、补充记录与处理时限 |
| 仲裁操作 | 驳回、要求补充、退还额度、处罚回写；结论必须填写理由 |
| 审批 | 需要双人审批的操作进入审批状态，未批准前不改变余额或处罚结果 |

### ADM-06 品类、区域与规则配置

| 配置 | 必填内容 |
| --- | --- |
| 品类 | 名称、开放状态、动态字段、必填规则、规格枚举、高危资质要求 |
| 区域 | 城市、行政区、开放状态、服务半径和首发范围 |
| 匹配规则 | 允许的必配规格、权重说明、优先窗口、推送额度 |
| 版本 | 草稿、差异预览、提交审批、生效、回滚；所有生效配置必须带版本号 |

### ADM-07 审计与导出申请

审计记录可按对象、操作人、时间、城市、操作类型检索，展示前后快照和理由。包含敏感字段或超过 50 条的导出必须创建申请，经过审批后生成带水印、脱敏范围受控的结果。

## 5. 跨页面规则

1. 联系方式只有“已解锁、归属本人、未撤销、用途仍有效”时才可展示。
2. 精确位置只用于匹配；所有公开页面显示行政区和距离区间。
3. 所有状态由服务端结果驱动，倒计时、可解锁按钮、审核入口不能依赖前端隐藏。
4. AI 只可生成识别建议、摘要和去重提示；用户确认和规则校验是发布与匹配的前置条件。
5. 额度、退款、处罚、配置发布、关闭需求、提交申诉均为关键操作，必须提供确认、结果、历史记录与失败恢复路径。
6. 任何角色都不能通过列表参数扩大城市、品类、敏感字段或联系方式的可见范围。
7. 首发阶段不存在自动调价、复杂路线匹配、公开服务质量画像和线下服务支付。
